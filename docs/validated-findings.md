# 已验证结果

[返回首页](../README.md) · [实验方法](methodology.md) · [证据索引](evidence-index.md)

**三端均完成真实业务与关键工程机制验证。**以下结果按独立实验批次说明，不将不同版本、输入或资源条件的结果混成一组。

## 1. 真实业务：9 个组合均具备成功回执

| 业务 | ACA | AKS | Foundry | 验收内容 |
|---|---|---|---|---|
| Trading 多 Agent 分析 | 已验证 | 已验证 | 已验证 | 原业务流程、真实行情数据、17 次模型请求、报告与结果导出 |
| 商品 RAG | 已验证 | 已验证 | 已验证 | 真实 CLIP/Chroma 商品索引、文本查询、1 次真实模型回答 |

这是**业务覆盖结论，不是 100% 请求成功率**。该批次保留 11 次原始尝试：9 次成功、2 次 Foundry 未确认；后续修正使用新的任务 ID，原记录未被删除或重发。

商品 RAG 固定 200 个商品。上述新批次的付费回答覆盖文本查询；图片与混合查询的检索、回放及早期真实生成属于其他批次，单独计数。

## 3. 十项工程维度的实际结论

| 维度 | 已确认的事实 | 工程结论 |
|---|---|---|
| **P1 编程模型** | 五种实现完成三端工具与历史验收 | 业务可以通过统一契约迁移 |
| **P2 执行模型** | 任务、事件和结果使用同一账本关联，已完成回执与去重读回 | 将任务生命周期与客户端连接分离 |
| **P3 状态与恢复** | 三端完成 checkpoint、十次团队状态更新、权限对照、断线与协调服务重启；连续 1,800.015 秒无请求后应用状态保留 | 采用持久状态和显式恢复，而不是依赖进程内存 |
| **P4 应用隔离** | 两个工作区分别完成私有输入、257 项计算与 512×320 PNG；越权访问被拒绝，子进程不接收云凭据 | 将应用 ACL、工作区绑定和凭据隔离落实到实际访问路径 |
| **P5 业务运行** | 三端均取得真实 Trading、RAG、工具会话成功回执 | 业务运行可行性已得到直接验证 |
| **P6 私网连接** | 共同私有 API 的 DNS/TLS、成功访问和拒绝端口对照均有数据面结果 | 企业接入应检查真实解析与连接 |
| **P7 身份授权** | 共同 Vault/Storage 的工作负载身份允许与拒绝对照均通过 | 对每个执行身份配置最小权限并验证拒绝路径 |
| **P8 故障定位** | 工具子进程真实超时、退出，并关联任务、版本、原生 job 与错误事件 | 运维界面应定位同一故障链路 |
| **P9 升级回滚** | 三端完成在途 V1、V2 Trading/RAG、回滚后 V1 Trading/RAG；Foundry 旧原生 session 保持版本和回执绑定 | 用实际业务与版本绑定验收发布 |
| **P10 费用核算** | 取得模型用量估算、业务子进程采样、资源账单与真实空闲观察 | 分开核算推理、基础设施、共享层和工程成本 |

这些是表中指定范围的结果，不是完整 P1–P10 生产验收评分。P4 的应用权限验证不替代平台隔离安全评估；P8 捕获了预期故障，注入任务本身仍记录为失败。

## 4. 恢复和发布的量化结果

| 项目 | 结果 | 解释 |
|---|---|---|
| Worker 终止后的 checkpoint 对照 | 关闭时 27 次固定模型操作，开启后 23 次；两组均有 15 个副作用且各执行一次 | 三端分别完成确定性机制探针，真实 provider 请求为零 |
| 客户端断开 | 每端 10 秒断开后，原任务完成 | 重连读取原任务，不新建任务 |
| 协调服务重启 | boot 标识变化，持久状态和已完成回执保留 | 被中断任务保持未确认，不自动重新派发 |
| 无请求状态保留 | 1,800.015 秒 | 核对窗口内宿主调用为零，证明应用状态保留 |
| 升级与回滚 | 每端各 2 个升级业务任务、2 个回滚业务任务 | Trading/RAG 都有实际结果，原失败保留 |
| 资源空闲观察 | 1,945.125 秒 | 与状态保留实验分开计时，不作为精确空闲费用 |
